# Hospital de los Costeños con Narcolepsia

Hospital management system written in Go that records patients with narcolepsy, their sudden sleep episodes, room assignment and the staff that attends them.

> Work in progress. This document is completed in stage 9.

## Author

- Valeria (ValeriaGC23)

## Requirements

- Go 1.21 or later

## Run

```sh
go run .
```
